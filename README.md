# Project
# 基于“一带多”增强模式的北斗差分路由器 📡

> [cite_start]本仓库为东南大学仪器科学与工程学院“大学生创新创业训练计划/课外研学”结题项目文档归档 [cite: 172, 175, 177][cite_start]。包含完整的项目结题报告与答辩 PPT [cite: 173, 166]。

## 💡 项目背景
[cite_start]在传统的北斗高精度定位服务中，主流的实时网络动态差分技术多采用“单终端独立通信”模式 [cite: 212][cite_start]。这种模式在终端密集的场景下，暴露出资源利用率低、终端成本高、服务端并发压力大，以及敏感位置信息上云带来的安全风险等问题 [cite: 208, 212]。

## 🚀 核心创新与解决方案
[cite_start]本项目创新性地将**边缘计算理念**深度融入北斗地基增强服务体系 [cite: 209, 214][cite_start]，提出并实现了一种低功耗、可扩展的区域差分播发新模式 [cite: 31]。

[cite_start]系统构建了**“云端–边缘节点–终端”**的三级协同架构 [cite: 208, 304]：
1. [cite_start]**云端接收**：边缘节点作为 Ntrip 客户端，从 CORS 服务端实时获取 RTCM 格式的差分数据 [cite: 258, 391]。
2. [cite_start]**边缘研判**：在边缘节点本地进行 CRC 校验，并通过节点内置的 RTK 定位模块对差分数据进行有效性研判（若无法实现固定解，则自动启动本地差分保持模式） [cite: 267, 392]。
3. [cite_start]**LoRa 广播**：利用基于 SX1268 芯片的 LoRa 无线通信模块（型号 L32_433UD22S），将有效差分数据在区域内进行广播 [cite: 208, 273, 394]。
4. [cite_start]**终端定位**：区域内的终端接收差分数据，结合自身 GNSS 观测值实现厘米级高精度的 RTK 固定解，达成“一带多”服务 [cite: 49, 208, 228, 397]。

## 📊 实验与性能测试
通过软硬件协同设计与三大核心实验验证：
* [cite_start]**有效工作范围**：在 0-800 米范围内，LoRa 数据传输成功率稳定在 80% 以上，支持终端稳定获得 RTK 固定解 [cite: 208, 295]。
* [cite_start]**“一带多”能力**：成功验证了单个边缘节点可有效同时服务至少两个终端，接收端的数据传输成功率分别达到 94.87% 和 93.13%，充分验证了系统的并发服务能力与稳定性 [cite: 208, 299, 301]。
